# Stats

> Stats is part of Eurth's 2026 advent calendar. Its door opens on 14 December, so please don't spoil the surprise before then.

Is my nation realistic? A free plausibility checker for worldbuilders: enter your nation's numbers and see how they compare with real modern countries. Made by [Eurth](https://eurth.org), a worldbuilding and roleplay community since 2004.

Status: being built. Nothing runs yet. See the [roadmap](roadmap.md) for the plan, where to pick up, what each release added and what's not planned.
